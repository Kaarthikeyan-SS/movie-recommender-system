# Movie Recommender System
This project is a Movie Recommender System built using Streamlit for the web interface, LangChain for prompt templating, and Google’s Generative AI (PaLM API) for generating personalized movie recommendations based on user input.

# Features
* Interactive User Input: Users can enter movie titles, genres, or keywords to get movie recommendations.
* AI-Powered Recommendations: The system uses Google Generative AI (PaLM API - Gemini) to suggest movies based on user input.
* Simple Web Interface: Built with Streamlit to provide a user-friendly and responsive UI.

# How It Works
* The user enters a movie title, genre, or keyword.
* A prompt is generated using the LangChain library.
* Google Generative AI processes the prompt to generate movie recommendations.
* Recommendations are displayed on the Streamlit interface.
# Requirements
To run this project, you'll need:
* Python 3.7+
* Google PaLM API Key (You can get one from Google Cloud)
# Required Python libraries:
* streamlit
* langchain
* langchain_google_genai
* google-generativeai
* python-dotenv
